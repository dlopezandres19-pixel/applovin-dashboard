Methodology & caveats

  • What is counted: websites where BuiltWith detects AppLovin's tracking pixel (Axon). A site with the pixel is not necessarily an active, paying advertiser.
  • Live vs. redirects: BuiltWith also lists domains that only redirect to a live site; these are excluded. Third-party trackers that quote larger totals typically include them.
  • Restatements: BuiltWith re-crawls and can revise past weeks. The series always shows the latest figures; revisions are logged above.
  • Churn: BuiltWith only reports "expired" sites for the current date, so gross adds and churn start from the first automated weekly run. A site can move from expired back to live, so churn is approximate.
  • Weeks are anchored on Saturdays, matching the points on BuiltWith's own chart.
